# B站自定义倍速油猴脚本

一个功能强大的 Bilibili 视频播放倍速控制油猴脚本，支持自定义倍速调节、信息卡片显示、控制面板配置等功能，方便学习网课和高效观看视频。

## 功能特性

### 倍速控制

- 支持 0.5x ~ 2.0x 倍速调节（可通过高级选项扩展至 0.3x ~ 5.0x）
- 步进值默认为 0.05，可选 0.02、0.05、0.10
- 支持快捷键操作和可视化 Toast 提示

### 信息卡片 (CardPanel)

- 显示当前倍速、剩余时间、总时长
- 可拖拽的进度条，支持点击定位和拖拽跳转
- 播放/暂停控制按钮
- 合集总时长显示（自动检测合集视频）
- 鼠标悬停显示操作按钮
- 可拖拽到任意位置（位置自动保存）

### 控制面板 (ControlPanel)

- 步进值设置（0.02 / 0.05 / 0.10）
- 初始倍速设置（0.8x / 0.9x / 1.0x / 1.1x / 1.25x）
- 高级选项（连续点击标题 5 次显示/隐藏）：
  - 最小倍速设置
  - 最大倍速设置
  - 快捷键自定义
- 重置 / 保存配置

### 智能适配

- 自动检测宽屏/网页全屏模式，隐藏信息卡片
- 支持 SPA 页面切换，自动重新初始化
- 自动检测合集视频并显示总时长
- 输入框聚焦时禁用快捷键，避免误触

### 配置持久化

- 所有配置自动保存到 GM_setValue/GM_getValue
- 面板位置自动记忆
- 支持通过油猴菜单命令操作

## 安装

### 前置条件

- 安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/) 浏览器扩展

### 安装步骤

1. 复制 `bbb.js` 的全部内容
2. 打开油猴扩展管理面板
3. 创建新脚本
4. 粘贴代码并保存

## 使用方法

### 默认快捷键

| 快捷键 | 功能 |
|--------|------|
| `X` | 减速（减少步进值） |
| `C` | 加速（增加步进值） |
| `Z` | 重置为默认倍速 |

> 快捷键可在控制面板的高级选项中自定义（不支持 F 键）

### 油猴菜单

脚本会在油猴菜单中注册以下命令：

- **切换信息卡片** - 显示/隐藏信息卡片
- **打开控制面板** - 打开控制面板进行配置

### 信息卡片操作

- **拖拽**：按住信息卡片标题区域拖拽移动
- **进度条**：点击定位 / 拖拽跳转
- **播放/暂停**：点击卡片底部的播放/暂停按钮
- **操作按钮**：鼠标移入卡片显示，移出自动隐藏
- **关闭卡片**：点击卡片右上角的 X 按钮

### 控制面板操作

- **步进值**：选择调速精度（0.02 / 0.05 / 0.10）
- **初始倍速**：选择默认播放倍速
- **高级选项**：连续点击面板标题"控制面板"5 次，可显示/隐藏高级设置（最小倍速、最大倍速、快捷键自定义）
- **保存**：保存当前配置
- **重置**：恢复默认配置

## 不启用脚本的页面

以下页面脚本会自动禁用：

- 直播页面 (`/live/`)
- 首页 (`/`)
- 个人空间 (`space.bilibili.com`)
- 创作中心 (`member.bilibili.com`)

## 注意事项

- 快捷键修改后需要刷新页面才能生效
- 信息卡片在宽屏/网页全屏模式下会自动隐藏
- 切换视频页面后脚本会自动重新初始化
- 进度条在拖动时会实时更新视频播放位置

## 技术实现

- 纯原生 JavaScript 实现，无外部依赖
- 使用 Proxy 实现配置的自动读写和持久化
- 事件委托监听播放器模式变化
- 定时检测 URL 变化支持 SPA 页面切换
- 节流函数优化频繁操作的性能
- 输入框焦点检测避免快捷键冲突
