# 视频笔记功能开发计划 v1

## 1. 项目概述

为 bilibiliv18 油猴脚本新增视频笔记功能，允许用户在观看B站视频时记录笔记，支持 Quill 富文本编辑器和 Vditor Markdown 编辑器两种编辑模式，提供笔记的创建、编辑、搜索、分类、删除等完整管理能力。

### 2.2 核心架构模式

| 模式 | 说明 | 示例 |
|------|------|------|
| IIFE 闭包模块 | 每个模块使用立即执行函数封装，暴露公共API | `const Favorites = (() => { ... return { add, remove, ... }; })();` |
| EventBus 事件总线 | 模块间通过事件通信，解耦依赖 | `EventBus.emit('favorites:toggle')` / `EventBus.on('favorites:updated', callback)` |
| Proxy 响应式配置 | Config 使用 Proxy 拦截读写，自动持久化到 GM_setValue | `Config.data.theme = 'dark'` 自动触发 `GM_setValue('theme', 'dark')` |
| Card 组件化构建 | 所有面板基于 Card.create() 构建，统一 header/body/footer 结构 | CardPanel、ControlPanel、FavoritesPanel 均使用 Card |
| 构建时模块拼接 | build.js 按依赖顺序读取各模块文件，拼接注入 index.js 模板 | `// MODULE_INJECTION_POINT` 占位符替换 |

### 2.3 数据持久化方案

- 使用油猴 API `GM_setValue(key, value)` / `GM_getValue(key)` 存取数据
- 数据以 JSON 格式存储，key 为模块名（如 `'favorites'`）
- Config 模块通过 Proxy 实现配置项的自动持久化

### 2.4 UI 构建模式

所有面板视图遵循统一构建模式：

```javascript
panelInstance = Card.create({
```

### 2.5 ControlPanel 菜单导航模式

ControlPanel 采用左右分栏布局，左侧菜单导航切换右侧内容：

```javascript
let currentMenu = 'speed';

function switchMenu(menuName) {
    currentMenu = menuName;
    // 更新菜单项激活状态
    panelEl.querySelectorAll('.bili-speed-panel-menu-item').forEach(item => {
        item.classList.toggle('active', item.dataset.menu === menuName);

    // 渲染对应内容
    const contentEl = panelEl.querySelector('.bili-speed-panel-content');
    switch (menuName) {
        case 'system': renderSystemMenu(contentEl); break;
        case 'speed': renderSpeedMenu(contentEl); break;
        case 'favorites': renderFavoritesMenu(contentEl); break;
    }
}
```

## 3. 数据模型设计

### 3.1 笔记实体结构

```javascript
{
    id: string,              // 笔记唯一标识，格式：'note_' + timestamp + random
    bvid: string,            // 关联视频BV号
    videoTitle: string,      // 视频标题（冗余存储，便于列表展示）
    videoUrl: string,        // 视频URL
    editorType: string,      // 编辑器类型标识：'quill' | 'vditor'
    title: string,           // 笔记标题
    content: string,         // 笔记内容（Quill为HTML字符串，Vditor为Markdown字符串）
    contentDelta: string,    // Quill编辑器的Delta JSON字符串（仅quill类型使用，用于精确还原编辑状态）
    tags: string[],          // 标签数组，用于分类筛选
    videoTimestamp: number,  // 记笔记时的视频时间点（秒），0表示不关联时间点
    createdAt: number,       // 创建时间戳
    updatedAt: number        // 最后修改时间戳
}
```

### 3.2 存储方案

| 存储项 | Key | 类型 | 说明 |
|--------|-----|------|------|
| 笔记数据 | `'notes'` | `Array<Note>` | 所有笔记的数组 |
| 笔记面板位置 | `Config.notesPanelPosition` | `{ left, top }` | 通过 Config Proxy 自动持久化 |
| 笔记面板可见性 | `Config.notesPanelVisible` | `boolean` | 通过 Config Proxy 自动持久化 |
| 默认编辑器 | `Config.defaultEditor` | `'quill'` | `'quill'` 或 `'vditor'`，通过 Config Proxy 持久化 |

### 3.3 Config 新增配置项

在 Config.DEFAULTS 中新增：

```javascript
notesPanelVisible: false,
notesPanelPosition: null,
defaultEditor: 'quill'
```

### 3.4 数据关联关系

```
笔记(Note) ──N:1──> 视频(BV号)
    通过 bvid 字段关联
    同一视频可有多条笔记
    笔记通过 videoTimestamp 关联到视频的特定时间点
```

### 3.5 数据校验与安全

参考 Favorites 模块的 `validateItem` / `sanitizeItem` 模式：

- `validateNote(note)`: 校验必填字段（id, bvid, editorType, title, content）
- `sanitizeNote(note)`: 对文本字段进行 HTML 转义防止 XSS，对数值字段进行边界校验
- 笔记数量上限：500 条（避免 GM_setValue 存储溢出）
- 单条笔记内容大小限制：50KB（防止超长内容导致存储异常）

## 5. 详细功能设计

### 5.1 Notes 数据模块 (`src/modules/Notes.js`)

#### 5.1.1 API 设计

| 方法 | 功能 | 参数 | 返回值 |
|------|------|------|--------|
| `add(note)` | 添加笔记 | `note`: 笔记对象 | `boolean` |
| `update(id, updates)` | 更新笔记 | `id`: 笔记ID, `updates`: 更新字段对象 | `boolean` |
| `remove(id)` | 删除笔记 | `id`: 笔记ID | `boolean` |
| `get(id)` | 获取单条笔记 | `id`: 笔记ID | `object/null` |
| `getAll()` | 获取所有笔记 | 无 | `array` |
| `getByBvid(bvid)` | 按视频BV号查询笔记 | `bvid`: BV号 | `array` |
| `search(keyword)` | 按关键词搜索笔记 | `keyword`: 搜索关键词 | `array` |
| `getByTag(tag)` | 按标签筛选笔记 | `tag`: 标签名 | `array` |
| `getAllTags()` | 获取所有标签 | 无 | `array` |
| `count()` | 获取笔记总数 | 无 | `number` |
| `countByBvid(bvid)` | 获取指定视频的笔记数 | `bvid`: BV号 | `number` |
| `clear()` | 清空所有笔记 | 无 | `void` |
| `exportData()` | 导出笔记数据 | 无 | `string` (JSON) |
| `downloadExport()` | 下载导出文件 | 无 | `void` |
| `importData(jsonString)` | 导入笔记数据 | `jsonString`: JSON字符串 | `boolean` |

#### 5.1.2 事件定义

| 事件名 | 触发时机 | 携带数据 |
|--------|----------|----------|
| `notes:updated` | 笔记数据发生任何变更 | 无 |
| `notes:add` | 添加笔记成功 | 新增的笔记对象 |
| `notes:remove` | 删除笔记成功 | 被删除的笔记对象 |
| `notes:update` | 更新笔记成功 | 更新后的笔记对象 |

#### 5.3.2 技术实现要点

**CDN 引入方式**：

```javascript
function loadQuillResources() {
    return new Promise((resolve, reject) => {
        if (window.Quill) {
            resolve();
            return;
        }

        const css = document.createElement('link');
        css.rel = 'stylesheet';
        css.href = 'https://lf26-cdn-tos.bytecdntp.com/cdn/expire-1-M/quill/2.0.0-dev.4/quill.snow.css';
        document.head.appendChild(css);

        const script = document.createElement('script');
        script.src = 'https://lf26-cdn-tos.bytecdntp.com/cdn/expire-1-M/quill/2.0.0-dev.4/quill.js';
        script.onload = resolve;
        script.onerror = () => reject(new Error('Quill 资源加载失败'));
        document.head.appendChild(script);
    });
}
```

**编辑器初始化**：

```javascript
const quill = new Quill('#quill-editor-container', {
    theme: 'snow',
    placeholder: '开始记录笔记...',
    modules: {
        toolbar: [
            ['bold', 'italic', 'strike', 'underline'],
            [{ header: 2 }],
            ['blockquote'],
            [{ list: 'ordered' }, { list: 'bullet' }],
            ['link'],
            ['clean']
        ]
    }
});
```

**数据读写**：

- 读取内容：`quill.root.innerHTML` 获取 HTML，`JSON.stringify(quill.getContents())` 获取 Delta
- 写入内容：`quill.clipboard.dangerouslyPasteHTML(html)` 设置 HTML，`quill.setContents(delta)` 设置 Delta
- 保存时同时存储 `content`（HTML）和 `contentDelta`（Delta JSON），确保下次编辑时能精确还原

#### 5.4.2 技术实现要点

**CDN 引入方式**：

```javascript
function loadVditorResources() {
    return new Promise((resolve, reject) => {
        if (window.Vditor) {
            resolve();
            return;
        }

        const css = document.createElement('link');
        css.rel = 'stylesheet';
        css.href = 'https://cdn.jsdelivr.net/npm/vditor/dist/index.css';
        document.head.appendChild(css);

        const script = document.createElement('script');
        script.src = 'https://cdn.jsdelivr.net/npm/vditor/dist/index.min.js';
        script.onload = resolve;
        script.onerror = () => reject(new Error('Vditor 资源加载失败'));
        document.head.appendChild(script);
    });
}
```

**编辑器初始化**：

```javascript
const vditor = new Vditor('vditor-editor-container', {
    height: 360,
    mode: 'ir',
    toolbar: ['headings', 'bold', 'italic', 'strike', 'link', 'code', 'table', 'upload'],
    placeholder: '开始记录笔记...',
    cache: { enable: false },
    after: () => {
        if (existingContent) {
            vditor.setValue(existingContent);
        }
    }
});
```

**数据读写**：

- 读取内容：`vditor.getValue()` 获取 Markdown
- 写入内容：`vditor.setValue(markdown)` 设置 Markdown
- Vditor 不需要额外存储 Delta，Markdown 本身即为可编辑格式

## 9. 技术选型说明

### 9.1 编辑器对比

| 对比项 | Quill | Vditor |
|--------|-------|--------|
| 编辑模式 | 所见即所得（WYSIWYG） | Markdown（即时渲染/分屏预览） |
| 输出格式 | HTML + Delta JSON | Markdown |
| CDN 体积 | ~200KB (JS+CSS) | ~500KB (JS+CSS) |
| 学习成本 | 低，类似Word操作 | 中，需了解Markdown语法 |
| 适用场景 | 快速记录、非技术用户 | 技术笔记、代码片段、格式化需求高 |
| 主题定制 | 支持，通过CSS覆盖 | 支持，内置暗色主题 |
| 移动端适配 | 一般 | 较好 |

### 9.2 CDN 资源选择

| 资源 | CDN 地址 | 选择理由 |
|------|----------|----------|
| Quill CSS | `https://lf26-cdn-tos.bytecdntp.com/cdn/expire-1-M/quill/2.0.0-dev.4/quill.snow.css` | 与项目 docs 中参考一致，字节CDN国内访问快 |
| Quill JS | `https://lf26-cdn-tos.bytecdntp.com/cdn/expire-1-M/quill/2.0.0-dev.4/quill.js` | 同上 |
| Vditor CSS | `https://cdn.jsdelivr.net/npm/vditor/dist/index.css` | 与项目 docs 中参考一致，jsDelivr 稳定可靠 |
| Vditor JS | `https://cdn.jsdelivr.net/npm/vditor/dist/index.min.js` | 同上 |

### 9.3 懒加载策略

编辑器资源采用懒加载策略，仅在用户首次打开对应编辑器时加载：

1. 用户点击"新建笔记"或"编辑笔记"时，检查编辑器资源是否已加载
2. 若未加载，显示加载提示（如"正在加载编辑器资源..."），异步加载 CDN 资源
3. 资源加载完成后初始化编辑器并显示编辑面板
4. 若加载失败，显示错误提示并回退到简易 textarea 输入

## 11. 潜在风险评估与应对方案

### 11.1 CDN 资源加载风险

| 风险 | 等级 | 描述 | 应对方案 |
|------|------|------|----------|
| CDN 不可用 | 高 | 字节CDN或jsDelivr可能因网络问题无法访问 | 1. 实现加载超时检测（10秒）<br>2. 准备备用CDN地址<br>3. 加载失败时回退到简易 textarea 模式 |
| 资源版本变更 | 低 | CDN上的编辑器版本可能更新导致不兼容 | 使用固定版本号，不使用 latest 标签 |

### 11.2 数据存储风险

| 风险 | 等级 | 描述 | 应对方案 |
|------|------|------|----------|
| 存储空间溢出 | 高 | GM_setValue 存储容量有限（通常5-10MB），笔记内容可能很大 | 1. 限制笔记数量上限500条<br>2. 限制单条笔记内容50KB<br>3. 保存前检查数据大小<br>4. 提供导出功能让用户备份数据 |
| 数据丢失 | 中 | 脚本卸载或浏览器清理可能导致数据丢失 | 1. 提供导出/导入功能<br>2. 重要操作前提示用户备份 |
| XSS 注入 | 中 | 笔记内容可能包含恶意脚本 | 1. 对文本字段进行 HTML 转义<br>2. Quill 编辑器自带 XSS 防护<br>3. Vditor 渲染时启用安全模式 |

### 11.3 性能风险

| 风险 | 等级 | 描述 | 应对方案 |
|------|------|------|----------|
| 编辑器初始化慢 | 中 | CDN 资源加载和编辑器初始化需要时间 | 1. 懒加载策略，仅在需要时加载<br>2. 显示加载进度提示<br>3. 编辑器实例缓存，避免重复初始化 |
| 大量笔记渲染慢 | 低 | 笔记数量多时列表渲染可能卡顿 | 1. 限制单次显示数量，实现虚拟滚动或分页<br>2. 搜索时使用防抖（debounce） |
| 内存泄漏 | 中 | 编辑器实例未正确销毁 | 1. 面板关闭时正确调用编辑器销毁方法<br>2. 清理事件监听器<br>3. 使用 cleanupFns 模式统一管理 |

### 11.4 兼容性风险

| 风险 | 等级 | 描述 | 应对方案 |
|------|------|------|----------|
| B站页面结构变更 | 低 | B站可能更新页面DOM结构 | 1. 视频信息获取使用多重选择器降级<br>2. BV号从URL中提取，不依赖DOM |
| 油猴API差异 | 低 | 不同油猴扩展的GM_* API实现可能有差异 | 1. 使用前检测API可用性<br>2. 提供降级方案 |

### 11.5 编辑器冲突风险

| 风险 | 等级 | 描述 | 应对方案 |
|------|------|------|----------|
| 编辑器样式污染 | 中 | Quill/Vditor 的CSS可能影响B站页面样式 | 1. 使用 Shadow DOM 隔离样式<br>2. 或使用特定CSS前缀限定作用域<br>3. 面板关闭时移除编辑器DOM |
| 快捷键冲突 | 中 | 编辑器快捷键可能与脚本或B站快捷键冲突 | 1. 编辑器面板打开时禁用脚本快捷键<br>2. 利用 PageGuard.isInputFocused() 判断 |
| 编辑器实例冲突 | 低 | 同时打开两个编辑器实例可能导致异常 | 1. 同一时间只允许打开一个编辑器面板<br>2. 打开新编辑器前关闭已打开的编辑器 |

## 14. 开发规范

### 14.1 代码规范

- 遵循现有 IIFE 闭包模块模式
- 使用 `const Module = (() => { ... return { publicApi }; })();` 结构
- CSS 类名使用 `bili-speed-` 前缀 + kebab-case
- 事件名使用 `模块:动作` 格式（如 `notes:toggle`）
- 通过 EventBus 进行模块间通信，避免直接依赖
- 使用 Config.data Proxy 进行配置持久化
- 使用 cleanupFns Set 统一管理事件监听器清理

### 14.2 安全规范

- 所有用户输入文本必须经过 `escapeHtml` 转义
- 笔记内容在非编辑器上下文中展示时需进行安全过滤
- 导入数据时必须校验格式和字段有效性
- 限制数据存储量，防止存储溢出
